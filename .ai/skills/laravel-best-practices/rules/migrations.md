# Project Migration Authority

Do not apply an independent migration workflow from this skill.

Whenever migration work is created, edited, reviewed, or planned, activate and follow
`laravel-migration-workflow`. Its `SKILL.md` is the project's single source of truth for migration
lifecycle, batching, naming, constraints, indexes, rollback behavior, and verification.

If generic Laravel advice conflicts with `laravel-migration-workflow`, the project skill wins.
